# Expressive Compass — Android adaptive icon

Чистые векторные слои без растровой текстуры, градиентов, теней и 3D. Мягкая восьмилепестковая розетка и компас. Геометрия заново построена по утверждённому эскизу; это не растровая обводка.

## Содержимое
- `res/drawable/ic_launcher_background.xml`: сплошной мятный фон.
- `res/drawable/ic_launcher_foreground.xml`: зелёная розетка и молочный компас, прозрачность вокруг символа.
- `res/drawable/ic_launcher_monochrome.xml`: одноцветная alpha-маска с прозрачным рисунком компаса. Чёрный цвет является маской, а не итоговым цветом значка.
- `res/mipmap-anydpi-v26`: adaptive icon для Android 8–12.
- `res/mipmap-anydpi-v33`: adaptive icon с monochrome для Android 13+.
- `svg/`: редактируемые отдельные слои и два предпросмотра.

## Подключение
Скопировать содержимое `res/` в `app/src/main/res/`, заменив одноимённые ресурсы иконки. Перед заменой сохранить старые файлы. Manifest:

```xml
<application
    android:icon="@mipmap/ic_launcher"
    android:roundIcon="@mipmap/ic_launcher_round" />
```

Для сборки ресурсов monochrome нужен compileSdk 33+. В текущем приложении minSdk 26, поэтому legacy PNG не нужны. Этот комплект создан отдельно; ресурсы приложения не заменены.

## Системные цвета
На Android 13+ в совместимом launcher включить «Обои и стиль → Тематические значки». Launcher окрашивает monochrome-маску и фон под обои/системную тему. В обычном режиме используется мятно-зелёная палитра. Цветной foreground сам по себе не перекрашивается; не следует задавать цвет обоев в XML вручную. Форму внешней маски (круг, скруглённый квадрат и т. п.) выбирает launcher. `preview-round.svg` показывает круглый вариант.

Canvas 108×108; символ целиком внутри центральной безопасной области диаметром 66. Все слои имеют совпадающее положение. Проверить обе темы и оба режима значков на устройстве после установки.

Официальная документация: https://developer.android.com/develop/ui/compose/system/icon_design_adaptive
